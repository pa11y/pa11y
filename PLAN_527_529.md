# Implementation Plan: Close #527 and #529

## Issues
- **#527**: Group CLI arguments by runner (htmlcs, axe, common)
- **#529**: Parse and validate all CLI arguments before launching pa11y

## Root Cause
Both issues stem from the same place: `bin/pa11y.js` defines CLI options as a flat list with no central schema. Options are only validated late (in `lib/option.js::verifyOptions` which only checks `standard` and `page`/`browser` combo).

## Solution: Central Option Schema

Create a single source of truth: an **option schema** that defines:
- All CLI options with metadata (flags, description, type, runner scope, validation)
- Used for: (a) grouped help output, (b) early validation

## Files to Modify

### 1. `bin/pa11y.js` (main changes)
- Define `optionSchema` array with all options + metadata
- Build `commander` program dynamically from schema
- Add **early validation** function that runs after `program.parse()` but before `runProgram()`
- Print grouped help when `--help` is used

### 2. `lib/option.js` (minor)
- Keep `verifyOptions` for programmatic API validation (backward compat)
- Can be simplified since CLI now validates earlier

## Option Schema Design

```javascript
const optionSchema = [
  // Common options (all runners)
  { flags: '-r, --runner <runner>', desc: 'test runner(s): htmlcs (default), axe', type: 'string[]', runner: 'common', collect: true },
  { flags: '-c, --config <path>', desc: 'JSON/JS config file', type: 'string', runner: 'common', default: './pa11y.json' },
  { flags: '-t, --timeout <ms>', desc: 'timeout in milliseconds', type: 'number', runner: 'common' },
  { flags: '-w, --wait <ms>', desc: 'wait before tests in milliseconds', type: 'number', runner: 'common' },
  { flags: '-d, --debug', desc: 'output debug messages', type: 'boolean', runner: 'common' },
  { flags: '-R, --root-element <selector>', desc: 'CSS selector to limit tested page portion', type: 'string', runner: 'common' },
  { flags: '-E, --hide-elements <hide>', desc: 'CSS selector(s) to hide from testing', type: 'string[]', runner: 'common', collect: true },
  { flags: '-S, --screen-capture <path>', desc: 'save screen capture to path', type: 'string', runner: 'common' },
  { flags: '-l, --level <level>', desc: 'fail level: error, warning, notice', type: 'string', runner: 'common' },
  { flags: '-T, --threshold <number>', desc: 'permit N issues before failing', type: 'number', runner: 'common' },
  { flags: '-i, --ignore <ignore>', desc: 'issue types/codes to ignore', type: 'string[]', runner: 'common', collect: true },
  { flags: '--include-notices', desc: 'include notices in report', type: 'boolean', runner: 'common' },
  { flags: '--include-warnings', desc: 'include warnings in report', type: 'boolean', runner: 'common' },
  { flags: '-e, --reporter <reporter>', desc: 'reporter: cli (default), csv, json', type: 'string', runner: 'common' },
  { flags: '-n, --environment', desc: 'output environment info', type: 'boolean', runner: 'common' },

  // htmlcs-only options
  { flags: '-s, --standard <name>', desc: 'accessibility standard: WCAG2A, WCAG2AA (default), WCAG2AAA', type: 'string', runner: 'htmlcs' },
  { flags: '-A, --add-rule <rule>', desc: 'WCAG 2.0 rules to include', type: 'string[]', runner: 'htmlcs', collect: true },

  // axe-only options
  { flags: '--level-cap-when-needs-review <level>', desc: 'cap severity of needs-review issues: error (default), warning, notice', type: 'string', runner: 'axe' },
];
```

## Validation Rules (Early, Before Launch)

1. **Runner validation**: Each `--runner` value must be in `['htmlcs', 'axe']` or a valid custom runner path/module
2. **Standard validation**: If any runner is `htmlcs`, `--standard` must be in `['WCAG2A', 'WCAG2AA', 'WCAG2AAA']`
3. **Reporter validation**: `--reporter` must be in `['cli', 'csv', 'json', 'tsv', 'html']` or resolvable module
4. **Level validation**: `--level` must be in `['error', 'warning', 'notice', 'none']`
5. **Type coercion**: number options must parse to valid numbers
6. **Mutual exclusions**: e.g., `--environment` exits early (already handled)
